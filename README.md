# Stock Dashboard 更新說明

## 本次變更
- 進階選股條件中，已設定數值的欄位會以綠色外框、綠色底色與「✓ 已設定」標籤醒目顯示。
- 各條件區塊標題會顯示已設定欄位數，未設定區塊則顯示「尚未設定」。
- 快速策略每次被點擊時，都會明確將「PE 欄位版本」切換為「修正後本益比（缺值回退原始）」。
- PE 欄位版本預設為修正後本益比。
- 修正後本益比缺失或不是有效數字時，回退使用原始本益比。
- 清除進階條件後，PE 欄位版本也會恢復為修正後本益比。

## 上傳方式
將 `app.js` 和 `style.css` 更新到 GitHub Repository 根目錄並提交變更。`index.html` 本次無須更動。
